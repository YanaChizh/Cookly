Cookly

Cookly — веб-приложение для просмотра, фильтрации и добавления кулинарных рецептов с личным кабинетом пользователя.

Приложение позволяет просматривать рецепты, изучать ингредиенты и пошаговое приготовление блюд, а также добавлять собственные рецепты.

Стек технологий

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS
- SQLite
- Prisma ORM
- bcryptjs — хеширование паролей
- jose — JWT-сессии в HttpOnly cookie

Основной функционал

Главная страница ("/")

- Просмотр списка рецептов с фотографиями
- Название, категория, время приготовления и сложность
- Фильтрация по категориям: Все, Завтраки, Основные блюда, Супы, Салаты, Десерты, Напитки

Карточка рецепта ("/recipes/[id]")

- Фото и описание рецепта
- Время приготовления и количество порций
- Сложность приготовления
- Ингредиенты и пошаговое приготовление
- Редактирование и удаление рецепта после входа в аккаунт

Добавление рецепта ("/recipes/new")

- Форма добавления нового рецепта
- Название, категория, описание и фотография
- Время приготовления, порции и сложность
- Ингредиенты и шаги приготовления
- Сохранение рецептов в SQLite через Prisma ORM

Авторизация

- Регистрация ("/register")
- Вход в аккаунт ("/login")
- Личный кабинет ("/account")
- Выход из аккаунта

Пароль должен содержать минимум 8 символов. Пароли пользователей хранятся только в виде хеша. Для авторизации используются JWT-сессии, сохраняемые в HttpOnly cookie.

Запуск проекта

1. Клонирование репозитория

git clone <ссылка-на-репозиторий>
cd Cookly_simple

2. Установка зависимостей

npm install

3. Настройка окружения

Создайте файл ".env" в корне проекта и добавьте необходимые переменные окружения.

4. Подготовка базы данных

npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts

5. Запуск приложения

npm run dev

После запуска откройте в браузере: http://localhost:3000
