COOKLY — учебный проект УП.01
==============================
Тема: Разработка веб-приложения для просмотра и добавления рецептов с категориями

КАК ЗАПУСТИТЬ
1. Установите Node.js (LTS) с https://nodejs.org/
2. Распакуйте папку
3. Дважды нажмите start.bat
4. Откроется http://localhost:3000

ЧТО ЕСТЬ В ПРОЕКТЕ
- Главная страница с рецептами и фильтром по категориям
- Страница отдельного рецепта
- Регистрация, вход, выход, личный кабинет
- Добавление своих рецептов
- SQLite + Prisma
- Next.js 15 + TypeScript + Tailwind

Сделано в рамках учебной практики.
