# 🥞 Cookly

**Cookly** — веб-приложение для просмотра, фильтрации и добавления кулинарных рецептов с личным кабинетом пользователя.

## 🛠️ Стек технологий

- **Next.js 15** (App Router)
- **React**
- **TypeScript**
- **Tailwind CSS**
- **SQLite** — база данных
- **Prisma ORM** — работа с базой данных
- **bcryptjs** — хеширование паролей
- **jose** — создание и проверка JWT-сессий в HttpOnly cookie

## ✨ Основной функционал

### Главная страница (`/`)

- Просмотр списка рецептов с фотографиями
- Название, категория, время приготовления и сложность рецепта
- Фильтрация рецептов по категориям:
  - Все
  - Завтраки
  - Основные блюда
  - Супы
  - Салаты
  - Десерты
  - Напитки

### Карточка рецепта (`/recipes/[id]`)

- Фотография и описание рецепта
- Время приготовления и количество порций
- Уровень сложности
- Список ингредиентов
- Пошаговое приготовление
- **Редактирование и удаление рецептов после входа в аккаунт**

### Добавление рецепта (`/recipes/new`)

Форма добавления рецепта включает:

- Название и категорию
- Описание и фотографию
- Время приготовления
- Количество порций
- Сложность
- Ингредиенты
- Пошаговое приготовление

Рецепты сохраняются в **SQLite** с помощью **Prisma ORM**.

### 🔐 Авторизация

- **Регистрация** (`/register`) — имя, email и пароль от 8 символов
- **Вход** (`/login`)
- **Личный кабинет** (`/account`)
- **Выход из аккаунта**

Пароли хранятся только в виде хеша. Для авторизации используются JWT-сессии, которые хранятся в **HttpOnly cookie**.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <ссылка_на_репозиторий>
cd Cookly_simple
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example` и укажите необходимые переменные окружения.

### 4. Подготовка базы данных

```bash
npx prisma generate
npx prisma db push
```

### 5. Добавление начальных рецептов

```bash
npx tsx prisma/seed.ts
```

### 6. Запуск приложения

```bash
npm run dev
```

После запуска откройте в браузере:

**http://localhost:3000**
