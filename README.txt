Cookly
Веб-приложение для просмотра, фильтрации и добавления кулинарных рецептов с личным кабинетом пользователя.

Учебный проект по практике УП.01
Тема: «Рецепты с категориями»

Стек технологий
Next.js 15 (App Router) + React + TypeScript

Tailwind CSS

SQLite + Prisma ORM

bcryptjs — хеширование паролей

jose — JWT-сессии в HttpOnly cookie

Основной функционал
Главная (КАВЫЧКА/КАВЫЧКА)
список рецептов с фото, названием, категорией, временем и сложностью

фильтр по категориям: Все, Завтраки, Основные блюда, Супы, Салаты, Десерты, Напитки

Карточка рецепта (КАВЫЧКА/recipes/[id]КАВЫЧКА)
фото, описание, время, порции, сложность

ингредиенты и пошаговое приготовление

редактирование и удаление (после входа)

Добавление рецепта (КАВЫЧКА/recipes/newКАВЫЧКА)
форма: название, категория, описание, фото, время, порции, сложность, ингредиенты, шаги

сохранение в SQLite через Prisma

Авторизация
регистрация (КАВЫЧКА/registerКАВЫЧКА) — имя, email, пароль (минимум 8 символов)

вход (КАВЫЧКА/loginКАВЫЧКА)

личный кабинет (КАВЫЧКА/accountКАВЫЧКА)

выход

Пароли хранятся только в виде хеша. Сессия — в HttpOnly cookie.

Запуск проекта
1. Клонирование репозитория и переход в папку:

```bash
git clone <ссылка_на_репозиторий>
cd Cookly_simple
```

2. Установка зависимостей:

```
npm install
```

3. Создание файла .env:

```bash
cp .env.example .env
```

4. Подготовка базы данных и добавление стартовых рецептов:

```bash
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
```

5. Запуск сервера разработки:

```bash
npm run dev
```

Сайт будет доступен по адресу: http://localhost:3000
