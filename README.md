#  Cookly

**Cookly** — веб-приложение для просмотра, добавления и управления кулинарными рецептами.

##  Технологии

- **Next.js 15** — разработка веб-приложения
- **React + TypeScript** — интерфейс и логика
- **Tailwind CSS** — оформление
- **SQLite + Prisma ORM** — хранение и обработка данных
- **bcryptjs** — хеширование паролей
- **jose** — работа с JWT-сессиями

##  Возможности

- Просмотр рецептов с фотографиями и описанием
- Фильтрация по категориям
- Просмотр ингредиентов и пошагового приготовления
- Добавление, редактирование и удаление рецептов
- Регистрация и авторизация пользователей
- Личный кабинет и выход из аккаунта

##  Запуск проекта

** Клонировать репозиторий**

```bash
git clone <ссылка-на-репозиторий>
cd Cookly
```

** Установить зависимости**

```bash
npm install
```


** Подготовить базу данных**

```bash
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
```

**. Запустить приложение**

```bash
npm run dev
```

Открыть в браузере: **http://localhost:3000**
